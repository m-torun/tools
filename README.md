# tools

Small command-line utilities, one directory each.

| Tool | What it does |
|---|---|
| [fixpaste](fixpaste/) | Fixes clipboard text so it pastes into Apple Notes with proper paragraph spacing and rendered markdown |
| [hubfollow](hubfollow/) | Moves a Magic Keyboard and Mouse to whichever Mac a shared Dell monitor is showing |

Each directory is self-contained and carries its own README and install notes.
